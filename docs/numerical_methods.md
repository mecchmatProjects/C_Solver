## 1. Формули скінченних різниць

Для диференційовної функції $f(x)$ та малого додатного кроку $h > 0$:

* **Forward difference (права різниця):**
  $$D_{\text{forward}}(h) = \frac{f(x + h) - f(x)}{h}$$
  * Порядок похибки усічення (truncation error): $O(h)$.
  * Складність: 2 обчислення $f$.

* **Backward difference (ліва різниця):**
  $$D_{\text{backward}}(h) = \frac{f(x) - f(x - h)}{h}$$
  * Порядок похибки усічення: $O(h)$.
  * Складність: 2 обчислення $f$.

* **Central difference (центральна різниця):**
  $$D_{\text{central}}(h) = \frac{f(x + h) - f(x - h)}{2h}$$
  * Порядок похибки усічення: $O(h^2)$ для гладких функцій.
  * Складність: 2 обчислення $f$.

## 2. Компроміс вибору кроку $h$ (Truncation vs Round-off)

* **Надто велике $h$:** домінує похибка усічення формули ($O(h)$ або $O(h^2)$).
* **Надто мале $h$:** при відніманні майже рівних значень $f(x+h) - f(x)$ виникає втрата значущих цифр (floating-point cancellation / round-off error), і при діленні на дуже мале $h$ похибка знову зростає.
* Тому залежність похибки від $h$ немонотонна: спочатку вона зменшується, а після певного порогу починає зростати.
